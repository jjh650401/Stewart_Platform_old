### **檔案：驅動系統計算模組 - 開發規格書 v1.0**

**文件版本：1.0**
**日期：2025年9月3日**
**目的：** 本文件旨在為「史都華平台設計與模擬工具」專案中的「驅動系統計算」模組，提供一份統一、權威的開發規格。文件中詳細定義了專案目標、核心功能、統一的參數變數，以及必要的計算公式，以作為後續程式開發的唯一依據。

---

### **1.0 專案目標**

本開發任務的目標是，在現有的「史都華平台」專案基礎上，擴充一個功能完整的「電動缸驅動系統計算」模組。此模組需能輔助使用者，根據其設計需求與運動條件，驗證選用的主要零件（如螺桿、伺服馬達、皮帶輪）規格是否匹配，並估算其性能與壽命。

---

### **2.0 核心功能**

1.  **參數輸入**：提供一個獨立的使用者介面，讓使用者可以輸入電動缸的運作條件、運動剖面（Motion Profile）、以及壽命需求。
2.  **零件選型**：與現有的零件資料庫 (`parts.db`) 整合，允許使用者從資料庫中篩選並選定特定型號的伺服馬達、滾珠螺桿與皮帶輪。
3.  **性能計算**：根據輸入的參數與選定的零件規格，自動執行一系列工程計算，得出關鍵的性能指標。
4.  **結果校驗與顯示**：將計算結果（如需求扭矩、安全係數、估算壽命等）與選定零件的規格進行比較，並以清晰、結構化的方式將最終的校驗結果與性能數據呈現給使用者。

### **4.0 核心計算邏輯**

`[開發者註記：後端計算引擎 `drive_system_engine.py` 應根據以下公式進行實作。所有變數均已統一為程式變數名稱。]`

**重力加速度 (g)**: `9.81 m/s²`

1.  **運動負載 (Load Force Profile)**
    * 上升加速段 ($F_{ua}$): `moving_part_mass * g * (sin(install_angle) + friction_coeff * cos(install_angle)) + moving_part_mass * max_acceleration`
    * 上升等速段 ($F_{uc}$): `moving_part_mass * g * (sin(install_angle) + friction_coeff * cos(install_angle))`
    * 上升減速段 ($F_{ud}$): `moving_part_mass * g * (sin(install_angle) + friction_coeff * cos(install_angle)) - moving_part_mass * max_acceleration`
    * 下降加速段 ($F_{da}$): `moving_part_mass * g * (sin(install_angle) - friction_coeff * cos(install_angle)) + moving_part_mass * max_acceleration`
    * 下降等速段 ($F_{dc}$): `moving_part_mass * g * (sin(install_angle) - friction_coeff * cos(install_angle))`
    * 下降減速段 ($F_{dd}$): `moving_part_mass * g * (sin(install_angle) - friction_coeff * cos(install_angle)) - moving_part_mass * max_acceleration`
    * 靜止段 ($F_{s}$): `moving_part_mass * g * friction_coeff`

2.  **最大軸向負載 (Max Axial Force)**
    * `max_axial_force = max(F_ua, F_uc, F_ud, F_da, F_dc, F_dd, F_s)`

3.  **平均軸向負載 (Average Axial Force)**
    * $T_{total} = t_{ua} + t_{uc} + t_{ud} + t_{da} + t_{dc} + t_{dd} + t_s$
    * `$text{avg_axial_force} = ( (F_ua³ * t_ua/T_total) + (F_uc³ * t_uc/T_total) + ... ) ^ (1/3)`

4.  **需求扭矩 (Required Torque)**
    * 減速比 `gear_ratio = pulley_screw_teeth / pulley_motor_teeth` (若使用皮帶輪)
    * 螺桿導程 (米) `screw_lead_m = screw_lead / 1000.0`
    * `required_torque = (max_axial_force * screw_lead_m) / (2 * pi * screw_efficiency * gear_ratio * transmission_efficiency)`

5.  **靜態安全係數 (Static Safety Factor)**
    * `static_safety_factor = screw_coa / max_axial_force` (通常要求 $\geq 1.5$)

6.  **估算壽命 (Estimated Life Hours)**
    * *需先計算平均轉速 `avg_screw_speed`*
    * $L_{rev} = (screw\_ca / (avg\_axial\_force * load\_factor))³ * 10^6$
    * `estimated_life_hours = L_rev / (60 * avg_screw_speed)`
