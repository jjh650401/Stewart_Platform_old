**[開發者註記：版本變更日誌 (累積所有版本)]**

  - **[新增] [從 v1.21 穩定版 -> v1.22 穩定版]**
      - **[資料庫優化] 支援外部 Excel 匯入與設計條件零件篩選**：
          - **匯入功能**：支援三個 Excel 檔案（螺桿資料.xlsx、伺服馬達資料.xlsx、皮帶輪資料.xlsx）的匯入，新增額外欄位（pearl_dia_mm, rigidity_kg_um, servo_driver_model 等），處理重複型號（顯示差異，提供「跳過」、「覆蓋」、「新增」選項），缺少欄位預設值為 0 或空字串，max_length_mm 預設 2000。
          - **零件篩選**：根據計算結果篩選馬達、螺桿、皮帶輪。
            - 馬達篩選條件：required_motor_torque <= rated_torque_nm * (1 + (max_torque_nm - rated_torque_nm) / (2 * rated_torque_nm)), rated_torque_nm >= required_motor_torque, rated_rpm >= required_rpm。
            - 螺桿篩選條件：ca_n >= C_ac, C_ac = F_eq * f_w * ((60 * n_eq * L_T) / 10^6)^(1/3), diameter_mm >= 10 mm, 5 <= lead_mm <= 50 mm, 優先 required_lead_mm < lead_mm <= required_lead_mm * 1.1, 無則最接近 required_lead_mm, 驗證 L_t >= L_T, L_t = (ca_n / (F_eq * f_w))^3 * (10^6 / (60 * n_eq))。
            - 皮帶輪篩選條件：100% 精確匹配 ratio, 無匹配保留 ratio。
          - **負荷係數 f_w 處理**：根據 v_max 從 LOAD_FACTOR_RANGES 選擇 f_w。
          - **L_T 計算**：L_T = hours_per_day * days_per_year * expected_years * duty_cycle。
          - **L_t 驗證**：驗證 L_t >= L_T。
          - **異常處理**：新增異常處理、多重排序、預設值。
          - **更新開發規格書**：為此項重大修正，將《驅動系統計算模組 - 開發規格書》進版至 **v1.2**，確保文件與程式碼同步。

### **第一章：專案概述**

**專案名稱**：模組化史都華平台設計與模擬工具

**專案目標**：為遊樂設備行業的技術人員，提供一款參數化設計、性能分析、動態模擬與驗證的桌面應用程式，整合電動缸驅動系統設計功能。

**專案範圍**：包括平台幾何參數輸入、姿態計算、3D 視覺化、動態模擬、驅動系統計算等模組。

**專案原則**：模組化設計、易用性優先、物理準確性保障、跨平台兼容（Python + PyQt6）。

### **第三章：功能模組說明**

1.  **幾何參數輸入模組**：
    * 支援六自由度與三自由度模式。
    * 驗證參數有效性。
    * 存檔/讀檔功能 (.json)。

2.  **姿態計算與分析模組**：
    * 計算正向/逆向運動學。
    * 驗證角度與連桿長度。
    * 即時反饋錯誤。

3.  **3D 視覺化模組**：
    * 使用 PyVista 渲染平台模型。
    * 支援節點標籤、座標軸顯示。
    * 動畫模擬功能。

4.  **動態模擬模組**：
    * 計算慣性矩與負載。
    * 模擬運動軌跡。

5.  **驅動系統計算模組**：
    * 雙模式計算 (手動/自動)。
    * 零件篩選與扭矩計算。
    * 儀表板介面。
    * 支援 `.dsd` 存檔。

6.  **資料庫管理模組**：
    * 支援馬達、螺桿、皮帶輪管理。
    * Excel 匯入功能。
    * 重複型號處理 (跳過/覆蓋/新增)。

### **第四章：技術堆疊與依賴**

* **核心語言**：Python 3.10+
* **GUI 框架**：PyQt6
* **3D 視覺化**：PyVista, PyVistaQT
* **數學計算**：NumPy, SciPy
* **資料庫**：SQLite
* **測試框架**：Pytest
