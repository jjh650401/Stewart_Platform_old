### 完整修改計畫

以下是針對史都華平台設計與模擬工具專案（v1.21 穩定基線）的完整修改計畫，基於我們對話中所有討論和確認的需求。計畫涵蓋資料庫優化（支援外部 Excel 匯入與設計條件零件篩選）、GUI 修改（改為 QDialog，移除減速機）、篩選邏輯（馬達、螺桿、皮帶輪）、減速比輸入方式、負荷係數 f_w 處理、L_T 計算、L_t 驗證，以及其他細節（如異常處理、多重排序、預設值）。我已整合所有問答內容，確保不省略任何部分，並遵守「基礎背景與規則.md」的最高準則（保障既有功能穩定、提供完整程式碼、使用繁體中文、計畫先行、一次只做一個任務、在行動前尋求確認）。

#### 1. 任務總結與需求整合
- **主要需求**：
  - 資料庫優化：支援三個 Excel 檔案（螺桿資料.xlsx、伺服馬達資料.xlsx、皮帶輪資料.xlsx）的匯入，新增額外欄位（pearl_dia_mm, rigidity_kg_um, servo_driver_model 等），處理重複型號（顯示差異，提供「跳過」、「覆蓋」、「新增」選項），缺少欄位預設值為 0 或空字串，max_length_mm 預設 2000。
  - 零件篩選：根據計算結果篩選馬達、螺桿、皮帶輪。
    - 馬達篩選條件：required_motor_torque <= rated_torque_nm * (1 + (max_torque_nm - rated_torque_nm) / (2 * rated_torque_nm)), rated_torque_nm >= required_motor_torque, rated_rpm >= required_rpm。
    - 螺桿篩選條件：ca_n >= C_ac, C_ac = F_eq * f_w * ((60 * n_eq * L_T) / 10^6)^(1/3), diameter_mm >= 10 mm, 5 <= lead_mm <= 50 mm, 優先 required_lead_mm < lead_mm <= required_lead_mm * 1.1, 無則最接近 required_lead_mm, 驗證 L_t >= L_T, L_t = (10^6 / (60 * n_eq)) * (ca_n / (F_eq * f_w))^3。
    - 皮帶輪篩選條件：achievable_velocity >= v_max, width_mm 一致性檢查（不同則提示接受/拒絕）。
  - f_w 處理：根據 v_max 動態範圍（<15: 1.0~1.2, 15~60: 1.2~1.5, >=60: 1.5~3.0），預設值 1.1, 1.35, 2.2，GUI 提供調整和顯示。
  - ratio 處理：兩種輸入方式（輸入 ratio 或選擇皮帶輪），ratio >=1, 預設 2.0, 匹配 100% 精確, 無匹配提示調整, 保留 ratio 用於計算, GUI 顯示 ratio 和匹配結果。
  - L_T 計算：L_T = hours_per_day * days_per_year * expected_years * duty_cycle, 預設 8, 250, 5, 0.8, GUI 輸入並計算 L_T。
  - 異常處理：馬達 rated_torque_nm = 0 或 max_torque_nm <= rated_torque_nm 提示錯誤。
  - 多重排序：升序（馬達：rated_torque_nm, shaft_diameter_mm；螺桿：lead_mm, ca_n, diameter_mm；皮帶輪：ratio, width_mm）。
  - GUI 顯示：QLabel 顯示詳細參數（螺桿：型號, 桿徑, 導程, C_a, 廠牌；馬達：型號, 額定轉速, 額定扭力, 最高扭力, 廠牌；皮帶輪：型號, 齒數, 寬度, 直徑, 廠牌），過長換行。
  - 螺桿命名：統一為 screws (英文), 螺桿 (中文)。
  - config.py 更新：添加 SCREW_MIN_DIAMETER 等, LOAD_FACTOR_RANGES, DRIVE_DEFAULT_RATIO = 2.0。
- **開發原則**：
  - 保障既有功能穩定：修改僅限必要檔案，無影響其他模組。
  - 完整程式碼：所有修改檔案提供完整內容，不省略。
  - 繁體中文：註解和訊息使用繁體中文。
  - 計畫先行：以下詳細列出檔案清單、修改理由和實施細節。
  - 一次只做一個任務：整個優化視為單一任務（資料庫與篩選）。
  - 行動前尋求確認：計畫確認後再提供程式碼。

#### 3. 修改檔案清單與理由
共 5 個檔案修改，僅限必要部分：
1. **src/core/config.py**：
   - **理由**：集中管理螺桿參數 (SCREW_MIN_DIAMETER, SCREW_LEAD_MM_MIN, SCREW_LEAD_MM_MAX), LOAD_FACTOR_RANGES (f_w 範圍), DRIVE_DEFAULT_RATIO = 2.0。
2. **src/core/database_manager.py**：
   - **理由**：支援 Excel 匯入，新增額外欄位 (pearl_dia_mm 等), 處理重複型號 (duplicates 清單), 預設值 (max_length_mm = 2000), 統一螺桿表為 screws, 移除 reducers 表和 get_all_reducers。
3. **src/gui/controls/database_management_widget.py**：
   - **理由**：改為 QDialog, 添加確定/取消按鈕 (檢查關鍵欄位完整性, 髒旗提示存檔), 移除減速機選項, 處理 duplicates (顯示差異, 提供跳過/覆蓋/新增), 統一螺桿為「螺桿」。
4. **src/core/drive_system_engine.py**：
   - **理由**：實現篩選邏輯 (馬達: rated_torque_nm * safety_factor >= required_motor_torque 等, 螺桿: ca_n >= C_ac, diameter_mm >= 10 mm, lead_mm 5~50 mm, 優先 lead_mm, L_t >= L_T), f_w 選擇, ratio 匹配 (100% 精確, 無匹配保留 ratio), 引用 config.py 參數。
5. **src/gui/controls/drive_system_widget.py**：
   - **理由**：更新 GUI, 添加 f_w 調整 (QDoubleSpinBox, 範圍根據 v_max, 顯示 QLabel), ratio 輸入 (兩種模式, 預設 2.0, >=1, 顯示 QLabel, 匹配結果 QLabel), L_T 輸入 (hours_per_day 等, 預設值, 計算 L_T), 詳細參數顯示 (QLabel, 換行), 統一螺桿為「螺桿」。

- **不修改檔案**：其他檔案（如 main_window.py）不受影響，僅需確認 _open_database_manager 使用 dialog.exec()。
