## 史都華平台工作空間分析問題彙總
**文件目的**：本文件旨在為第三方顧問（AI 或人類專家）提供一個關於「模組化史都華平台設計與模擬工具」專案中，一個長期存在的、關於工作空間計算的頑固問題的完整背景。目標是尋求一個全新的、更穩健的解決方案。

1. 專案目標
本專案的核心目標之一，是精確計算史都華平台（6-DOF 與 3-DOF）的工作空間。這個計算必須考慮到兩種主要的物理限制：
- 電動缸行程限制：每一根連桿的長度必須在其最小與最大機械長度之間。
- 關節角度限制：每一根連桿與上下平台的夾角，不得超過其機械關節（如虎克接頭、球接頭）的最大允許擺動角度。

2. 核心問題
目前的程式 (v1.9 開發分支) 在處理這兩種限制時，表現出不一致的行為：
- 計算成功：當使用者僅啟用「電動缸行程限制」時，工作空間分析能夠成功且正確地計算出所有自由度的運動範圍。
- 計算失敗：一旦使用者同時啟用「電動缸行程限制」與「關節角度限制」，工作空間分析便會立即失敗，回傳所有自由度的運動範圍均為零。

3. 技術棧與關鍵檔案
- 程式語言: Python
- 核心函式庫: PyQt6 (UI), NumPy (數值運算), SciPy (最佳化)
- 問題根源檔案: 整個問題的計算邏輯，完全封裝在 src/core/kinematics.py 這個單一檔案中。

4. 當前的解決方案與實作細節
我們目前的作法，是將「尋找工作空間邊界」這個問題，轉化為一系列的約束最佳化 (Constrained Optimization) 問題。
- 求解器：我們目前採用的是 SciPy 函式庫中的 scipy.optimize.minimize 函式，並指定使用 SLSQP 演算法。
- 求解流程：為了找到每一個自由度（例如 Surge (X)) 的正負極限，我們會執行兩次最佳化：
1. 一次以「最大化 X 座標」為目標。
2. 一次以「最小化 X 座標」為目標。
- 目標函數 (Objective Function)：
- 這是一個非常簡單的線性函數，例如 f(pose) = -x (用於最大化 x)。
- 我們已經成功地為這個函數提供了其解析梯度 (Analytical Jacobian)，即 jac = [ -1, 0, 0, 0, 0, 0 ]，這解決了 SLSQP 先前遇到的數值不穩定問題。
- 約束條件 (Constraints)：
- 這是問題的核心所在。所有的物理限制，都被定義為一系列的「不等式約束條件」，其數學形式為 fun(pose) >= 0。
- 連桿長度約束：我們為每一根連桿都定義了兩個約束條件：
1. leg_length(pose) - min_length >= 0
2. max_length - leg_length(pose) >= 0
- 關節角度約束：當啟用時，我們為每一個基座關節和平台關節，都定義了一個約束條件：
1. max_angle - joint_angle(pose) >= 0
- 實作方式：在程式碼中，這些約束條件被建立成一個字典列表，並傳遞給 minimize 函式的 constraints 參數。

5. 總結：尋求新思路
儘管我們已經嘗試了多種方法（包括更換求解器至 trust-constr、引入數值擾動等），但只要「關節角度約束」被加入到求解任務中，計算就會失敗。
這表明，我們目前定義或組合這些約束條件的方式，與 SciPy 的求解器之間存在著根本性的不匹配。
我們誠懇地請求您，基於以上資訊和 kinematics.py 的完整程式碼，為我們提供一個全新的、更穩健的解決方案或除錯思路。
可能的探索方向包括但不限於：
- 是否有比 SLSQP 更適合此類高耦合、多約束問題的其他求解器演算法？

- 是否存在缺陷？是否有更聰明的數學方法來表述這些物理限制？是否存在某些數值處理技巧（例如，對約束條件進行正規化或縮放），是我們目前所遺漏的？
