## 1.0 專案概述與基礎需求

### **專案描述**

本專案旨在開發一個程式，用於輔助設計電動缸，並驗證選用的主要零件（如螺桿、伺服馬達、皮帶輪）規格是否符合設計要求。每種電動缸的設計需要將個別電動缸的設計相關資訊儲存在工作的電腦裡，以利後續取出來運用或修改。

### **程式基礎要求**
1.  **視窗環境：** 本程式需要在全視窗環境運行，所有資料的顯示和輸入都應在視窗環境中進行，並以常見的 Windows 程式形式規劃視窗介面。
2.  **模組化程式設計：** 將程式拆分為多個模組或函數，每個模組只負責一個特定的功能，使程式碼簡潔易維護。
3.  **類別組織：** 使用類別進行組織，將相關的功能放在類別中，使程式更具結構性和可擴展性。
4.  **文件和目錄結構管理：** 將程式碼分成不同的文件和目錄，有助於更好地管理和尋找程式碼。
5.  **模組設計與實作說明：** 為各模組提供設計與實作說明，包含通用工具函數，例如時間格式化、字符數檢查等。這些函數會在其他模組中被重複使用。
6.  **測試與驗證：** 撰寫單元測試以驗證各模組的功能。
7.  **配置檔案：** 引入配置檔案（例如 `.env` 或 `config.json`），避免將如 API 金鑰等敏感資訊硬編碼在程式中。這樣可以讓程式更靈活，且不必每次修改程式碼來更改配置。
8.  **日誌記錄：** 使用日誌記錄程式的運行狀態、錯誤訊息等，方便除錯和監控。
9.  **註解與文件：** 保持程式碼的簡潔和清晰，但對於複雜的邏輯，應當加入詳細的註解。同時，為每個模組撰寫簡單的文件說明（docstring），這樣可以幫助後續的開發者理解程式碼。

## 2.0 符號與變數定義

#### 說明
**變數定義：**
   - ${W}$：移動件重量，單位為 **${kg}$**。
   - $F_{i}$：需求電動缸軸向推力，單位為 **${N}$**。
   - $\theta$：為安裝角度(與水平面夾角)，通常以 **$^\circ$** 表示。
   - ${g}$：重力加速度(1${g}$ = 9.81 $\text{m/s}^2$)。
   - $\mu$：摩擦係數。
   - ${stroke}$：電動缸活塞或推桿可移動的最大距離，單位為 **${mm}$**。
   - $v_{max}$：電動缸(螺桿)在運行過程中能達到的最大線速度，單位為 **${m/s}$**。
   - $a_{max} $：電動缸(螺桿)能達到的最大加速度，單位為 **${m/s}^2$** 。
   - $t_{acc}$：電動缸(螺桿)從靜止加速到最大速度 $v_{max}$所需的時間，單位為 **${s}$** 。
   - $L_{t}$：螺桿總運行時間，單位為 **${hr}$**。

   - $R_{h}$：電動缸每日計劃運行的總時間，單位為 **${hr}$**，由程式提示使用者輸入。
   - $R_{d}$：電動缸每年運行的總天數，單位為 **${day}$**，由程式提示使用者輸入。
   - $R_{y}$：電動缸的預計使用總年限，單位為 **${year}$**，由程式提示使用者輸入。
   - ${Aval}$：運作稼動率，電動缸實際運作時間占可用時間的百分比（範圍： **$0 < {Aval} < 1$**），由程式提示使用者輸入，無單位。
     $
     Aval = \frac{\text{實際運作時間}}{\text{計劃運作時間}} \times 100\%
     $
 
   - $TN_{screw}$：螺桿型號，無單位。
   - $D_{N}$：螺桿軸外徑，單位為 **${mm}$**。
   - $l$：螺桿導程規格，單位為 **${mm}$**。
   - $D_{ball}$：螺桿珠徑規格(只有滾珠螺桿有此規格)，單位為 **${mm}$**。
   - $C_{a}$：螺桿動額定負荷規格 **${N}$ 或 ${kgf}$**。
   - $C_{oa}$：螺桿靜額定負荷規格，單位為 **${N}$ 或 ${kgf}$**。
   - $Bd_{screw}$：螺桿廠牌資訊，無單位。

   - $TN_{motor}$：馬達型號，無單位。
   - $TN_{controller}$：馬達控制器型號，無單位。
   - $P_{motor,rated}$：馬達額定功率規格，單位為 **${kW}$**。
   - $n_{motor,rated}$：馬達額定轉速規格，單位為 **${rpm}$**。
   - $T_{motor,rated}$：馬達額定扭力規格，單位為 **${Nm}$ 或 ${kgf-m}$**。
   - $T_{motor,peak}$：馬達峰值扭力規格，單位為 **${Nm}$ 或 ${kgf-m}$**。
   - $A_{motor,rated}$：馬達額定電流規格，單位為 **${A}$**。
   - $Bd_{motor}$：馬達廠牌資料，無單位。
   - $Bd_{controller}$：馬達控制器廠牌資訊，無單位。

   - $TN_{pully}$：皮帶輪型號，無單位。
   - $N_{pully, teeth}$：皮帶輪齒數規格，是整數值，無單位。
   - $D_{pully}$：皮帶輪直徑，單位為 **${mm}$**。
   - $W_{belt}$：皮帶輪適用皮帶寬度，單位為 **${mm}$**。
   - $Bd_{pully}$：皮帶輪廠牌資訊，無單位。
   - $N_{m}$：馬達端皮帶輪齒數，使用者由皮帶輪資料庫選取的皮帶輪規格取得齒數，為正的整數值。
   - $N_{s}$：螺桿端皮帶輪齒數，使用者由皮帶輪資料庫選取的皮帶輪規格取得齒數，為正的整數值。

   - $GR$：減速比，無單位，可根據以下條件計算：
     $
     GR = \frac{\text{馬達端齒輪齒數}}{\text{螺桿端齒輪齒數}} = \frac{N_m}{N_s}
     $

   - $F_{i}$：在某負載條件下的實際軸向負載，可為 $F_{ua}, F_{uc}, \dots, F_{s}$(見運行條件)。(i = ua, uc, ud, da, dc, dd, s)，預設單位為 **${N}$**。
   - $F_{ua}、F_{uc}、F_{ud}$：分別為加速上升、等速上升、減速上升段負載，預設單位為 **${N}$**。
   - $F_{da}、F_{dc}、F_{dd}$：分別為加速下降、等速下降、減速下降段負載，預設單位為 **${N}$**。
   - $F_{s}$：為靜止段負載，預設單位為 **${N}$**。
   - $F_{eq}$：平均軸向負載，預設單位為 **${N}$**。
   - $F_{max}$：靜態負載，預設單位為 **${N}$**。
     $
     F_{max} = max(F_{i}) \quad (i = ua, uc, ud, da, dc, dd, s)
     $

   - $t_{i}$：在某負載條件下的實際運行時間，可為 $t_{ua}, t_{uc}, \dots, t_{s}$(見運行條件)。(i = ua, uc, ud, da, dc, dd, s)，預設單位為 **${s}$**。
   - $t_{ua}、t_{uc}、t_{ud}$：分別為上升加速、上升等速、上升減速段的運行時間，預設單位為 **${s}$**。
   - $t_{da}、t_{dc}、t_{dd}$：分別為下降加速、下降等速、下降減速段的運行時間，預設單位為 **${s}$**。
   - $t_s$：為靜止段的運行時間，預設單位為 **${s}$**。
   - $T_{total}$：總運行時間，預設單位為 **${s}$**。
     $
     T_{total} = t_{ua} + t_{uc} + t_{ud} + t_{da} + t_{dc} + t_{dd} + t_s
     $

   - $t_{i,\%}$：各階段對應總運行時間的百分比。(i = ua, uc, ud, da, dc, dd, s)
      $
      t_{i,\%} = \frac{t_i}{T} \times 100 \quad (i = ua, uc, ud, da, dc, dd, s)
      $

   - $n_{i}$：在某負載條件下的實際螺桿轉速，可為 $n_{ua}, n_{uc}, \dots, n_{s}$(見運行條件)。(i = ua, uc, ud, da, dc, dd, s)，預設單位為 **${rpm}$**。
   - $n_{ua}、n_{uc}、n_{ud}$：分別為加速上升、等速上升、減速上升段螺桿轉速，預設單位為 **${rpm}$**。
   - $n_{da}、n_{dc}、n_{dd}$：分別為加速下降、等速下降、減速下降段螺桿轉速，預設單位為 **${rpm}$**。
   - $n_{s}$：為靜止段螺桿轉速，預設單位為 **${N}$**。
   - $n_{eq}$：平均螺桿轉速，預設單位為 **${N}$**。

   - $L_{rev}$：螺桿疲勞壽命，單位為 **${rev}$**。
   - $L_{s}$：螺桿總行程距離，單位為 **${km}$**。
   - $C_{ac}$：需求螺桿動額定負荷， 預設單位為 **${N}$**。
      
   - $C_{m}$：剛性修正係數，無單位。
   - $C_{N}$：臨界載荷修正係數
   - $Sup_{s}$：螺桿 Rod 端的固定方式，為邏輯值。
   - $f_{w}$：負荷係數(無單位，詳見負荷係數 **$f_{w}$** 表)，負荷係數與運動條件(震動/衝擊)及速度 **$v_{max}$** 有關。
   
   - $F_{req}$：由馬達扭力估算螺桿所產生的推力，預設單位為 **${N}$**。 
   - $T_{req}$：由推力估算螺桿所需扭矩，預設單位為 **${Nm}$**。 
   - $P_{req}$：螺桿所需馬達功率，預設單位為 **${kW}$**。 
   
   - $\eta$：機械效率，整體電動缸、馬達、皮帶輪系統的率效。

   - $S_{0}$：靜態安全係數

   - $v$：螺桿運動的直線速度，表示螺桿沿其運行方向的運動速率，通常由設計目標或運動條件給定，與最大速度 $v_{max}$ 比較，校驗設計是否合理，單位為 **${mm/s}$ 或 ${m/s}$**。
   - $v_{ref}$：參考線速度，通常是設計中設定的目標速度，與最大速度 $v_{max}$ 比較，校驗設計是否合理，單位為 **${mm/s}$** 或 **${m/s}$**。
   - $n_{motor,max}$：馬達的最大轉速，即馬達在短時間內能夠承受的最高轉速，用於限制螺桿的轉速計算，避免超過馬達性能，單位為 **${rpm}$**。
   - $n_{screw}$：螺桿的實際轉速，用於運動負載和等效負載的計算，單位為 **${rpm}$** 或 **${rev/s}$**。
     $
     n_{screw} = \frac{v}{l}
     $
   - $n_{screw,rpm}$：螺桿的轉速，與馬達轉速或等效轉速相關的計算中常用單位，單位為 **${rpm}$**。
     $
     n_{screw,rpm} = n_{screw,rev/s} \times 60
     $
   - $n_{screw,rev/s}$：螺桿的轉速，單位為 **${rev/s}$**。
     $
     n_{screw,rev/s} = \frac{n_{screw,rpm}}{60}
     $

## 3.0 設計資料輸入與校驗
### **由資料庫取得的零件規格參數**
#### **螺桿資料庫**
**由資料管理工具，讀取螺桿資料庫，可得以下資料：**
- **$TN_{screw}$**：螺桿型號，無單位。
- **$D_{N}$**：螺桿外徑規格，預設單位為 ${mm}$。
- **${l}$:**：螺桿導程規格，預設單位為 **${mm}$**。
- **$D_{ball}$**：螺桿珠徑螺桿規格，預設單位為 **${mm}$**。(只有滾珠螺桿有此規格)
- **$C_{a}$**：螺桿動額定負荷螺桿規格，預設單位為 **${N}$$**。
- **$C_{oa}$**：螺桿靜額定負荷螺桿規格，預設單位為 **${N}$$**。
- **$Bd_{screw}$**：螺桿廠牌資訊，無單位。

#### **馬達資料庫**
- **$TN_{motor}$：馬達型號**
- **$TN_{control}$：馬達控制器型號**
- **$P_{motor,rated}$**：馬達額定功率規格，單位為 **${kW}$**。
- **$n_{motor,rated}$**：馬達額定轉速規格，預設單位為 **${rpm}$**。
- **$T_{motor,rated}$**：馬達額定扭力規格，預設單位為 **${Nm}$**。
- **$T_{motor,peak}$**：馬達峰值扭力規格，預設單位為 **${Nm}$**。
- **$A_{motor,rated}$**：馬達額定電流規格，預設單位為 **${A}$**。
- **$Bd_{motor}$**：螺桿廠牌資料，無單位。
- **$Bd_{controller}$**：馬達控制器廠牌資訊，無單位。

#### **皮帶輪資料庫**
- **$TN_{pully}$**：皮帶輪型號，無單位。
- **$N_{pully, teeth}$**：皮帶輪齒數規格，是整數值，無單位。
- **$D_{pully}$**：皮帶輪直徑，預設單位為 **${mm}$**。
- **$W_{belt}$**：皮帶輪適用皮帶寬度，預設單位為 **${mm}$**。
- **$Bd_{pully}$**：皮帶輪廠牌資訊，無單位。

- **${GR}$**：減速比，使用者可以直接提供此值，也可根據以下條件計算：
    1. **$N_{m}$**：馬達端皮帶輪齒數，由使用者從皮帶輪資料庫中選取的皮帶輪規格取得齒數。
    2. **$N_{s}$**：螺桿端皮帶輪齒數，由使用者從皮帶輪資料庫中選取的皮帶輪規格取得齒數。
    $
    GR = \frac{馬達端皮帶輪齒數}{螺桿端皮帶輪齒數} = \frac{N_{m}}{N_{s}}
    $

### **需要使用者輸入的參數**
#### 以下資訊需由使用者輸入，以做為設計電動缸的設計依據：
- **$F_{i}$**：電動缸推力
- **$\theta$**：電動缸安裝角度 (預設$\theta$=90$^\circ$)
- **$stroke$**：電動缸活塞桿可移動的最大距離
- **$v_{max}$**：電動缸的直線運動最高速度
- **$a_{max}$**：電動缸的直線運動最大加速度
- **$t_{acc}$**：電動缸的加速時間

- **$t_{ua}$**：上升加速段的運行時間，預設單位為 **${s}$**。
- **$t_{uc}$**：上升等速段的運行時間，預設單位為 **${s}$**。
- **$t_{ud}$**：上升減速段的運行時間，預設單位為 **${s}$**。
- **$t_{da}$**：下降加速段的運行時間，預設單位為 **${s}$**。
- **$t_{dc}$**：下降等速段的運行時間，預設單位為 **${s}$**。
- **$t_{dd}$**：下降減速段的運行時間，預設單位為 **${s}$**。
- **$t_s$**：為靜止段的運行時間，預設單位為 **${s}$**。 

- **$L_{t}$**：螺桿總運行時間
  **使用者可以直接提供此值，也可根據以下條件計算：**
    1. **$R_{h}$**：電動缸每日計劃運行的總時間。
    2. **$R_{d}$**：電動缸每年運行的總天數。
    3. **$R_{y}$**：電動缸的預計使用總年限。
    4. **$Aval$**：電動缸運作稼動率，實際運作時間占可用時間的百分比。
- **$Sup_{s}$**：螺桿Rod端的固定方式。
   - **$Sup_{s}$**：為邏輯值：
     1. **$Sup_{s}$ = false**：表示固定方式為 **固定-自由**。
     2. **$Sup_{s}$ = true**：表示固定方式為 **固定-支撐**。
    剛性修正係數 $C_{m}$ 與臨界載荷修正係數 $C_{N}$ 的取值如下 $Sup_{s}$ 表，無單位：

      | 支撐條件 | $C_{m}$ | $C_{N}$ |
      |-----------|------|------|
      | 固定-支撐  | 10.20 | 2.00 |
      | 固定-自由  | 1.30  | 0.25 |

   - $f_{w}$：負荷係數與運動條件(震動/衝擊)及速度 $v_{max}$ 有關，使用者需輸入 $f_{w}$ 的值，並滿足以下限制：

      | **震動與衝擊** | **速度範圍 v_{max}$** | **$f_{w}$ 範圍** |
      |----------------|---------------------------------|------------------|
      | 輕             | $v_{max}$ < 15      | \( 1.0 \sim 1.2 \) |
      | 中             | 15 $\leq v_{max}$ < 60 | \( 1.2 \sim 1.5 \) |
      | 重             | $v_{max} \geq$ 60   | \( 1.5 \sim 3.0 \) |
      #### **條件定義**
      1. 可由 **$v_{max}$** 確定震動與衝擊類型(輕/中/重)。
      2. 使用者輸入的 $f_{w}$ 值必須符合對應類型的範圍：
         - 若 $v_{max}$ < 15，則 1.0 $\leq f_{w} \leq$ 1.2。
         - 若 15 $\leq v_{max}$ < 60，則 1.2 $\leq f_{w} \leq$ 1.5。
         - 若 $v_{max} \geq$ 60，則 1.5 $\leq f_{w} \leq$ 3.0。

#### **使用者輸入單位檢查**
為了避免計算過程中的單位不一致，程式應包含以下檢查機制：

#### **通用性輸入要求**
- **提示詞與單位選擇：**
  - 在每次要求輸入時，程式會顯示清晰的提示詞，幫助使用者理解輸入需求。
  - 提供多種常用單位供使用者選擇。例如：
    - **力的單位：${kfg}, {N}$**
    - **長度單位：${mm}, {cm}, {m}$**
    - **時間單位：${s}, {min}, {hr}, {day}, {year}$**
    - **速度單位：${m/s}, {mm/s}, {m/min}, {mm/min}$**
    - **加速度單位：${g}, {m/s}^2, {mm/s}^2$**
    - **扭力單位：${Nm}$, ${kgf} \cdot {m}$**

#### **數據核對與轉換邏輯**
1. **長度單位檢查：**
   - 確保輸入的 **${stroke}、{l}、{L}$**，默認單位為 **${mm}$**。
   - 在程式中，由清單方式提供單位選擇 **${mm} 或 {m}$**。
   - 若選擇為 **${mm}$**，程式將自動轉換為 **${m}$** 來進行計算。
     $
     Len(m) = Len(mm) \times 10^{-3}
     $

2. **推力單位檢查：**
   - 確保輸入的 **$F_{i}$** 默認單位為 **${N}$**。
   - 在程式中，由清單方式提供單位選擇 **${kgf}$** 或 **${N}$**。
   - 若選擇為 **${kgf}$**，程式將自動轉換為 **${N}$**。
     $
     F(N) = F(kgf) \times 9.81
     $

3. **扭力單位檢查：**
   - 確保輸入的 **$T$** 默認單位為 **${Nm}$**。
   - 在程式中，由清單方式提供單位選擇 **${kgf} \cdot {m}$** 或 **${Nm}$**。
   - **扭力**的單位轉換提示
   - 若選擇為 **${kgf} \cdot {m}$**，程式將自動轉換為 **${Nm}$**。

#### **單位轉換說明**
**程式需自動檢查輸入的單位，若用戶選擇的單位不一致(非默認單位)，程式會自動進行單位轉換。**
  例如：
  - **力： $1 \, kfg = 9.81 \times N$**
  - **長度： $1 \, m = 100 \times cm$**
  - **長度： $1 \, cm = 10 \times mm$**
  - **時間： $1 \, year = 365 \times day$**
  - **時間： $1 \, day = 24 \times hr$**
  - **時間： $1 \, hr = 60 \times min$**
  - **時間： $1 \, min = 60 \times s$**
  - **扭力：$1 \, {kgf} \cdot {m} = 9.81 \times Nm$**

### **錯誤處理**
- **程式會自動檢查數據格式的正確，程式會顯示具體提示，確保值在合理範圍內。**
- 如果輸入數據格式錯誤，程式會顯示具體提示，要求重新輸入：
  ```
  輸入錯誤：每日運作時數必須為正數，請重新輸入。
  ```

## 4.0 運作條件資訊

#### **(1) 運動負載公式**
$
F_{i} \quad (i = ua, uc, ud, da, dc, dd, s)
$

1. **上升加速段($F_{ua}$)**
$
F_{ua} = W \times g \times (\sin\theta + \mu \times \cos\theta) + W \times a_{max}
$

2. **上升等速段($F_{uc}$)**
$
F_{uc} = W \times g \times (\sin\theta + \mu \times \cos\theta)
$

3. **上升減速段($F_{ud}$)**
$
F_{ud} = W \times g \times (\sin\theta + \mu \times \cos\theta) - W \times a_{max}
$

4. **下降加速段($F_{da}$)**
$
F_{da} = W \times g \times (\sin\theta - \mu \times \cos\theta) + W \times a_{max}
$

5. **下降等速段($F_{dc}$)**
$
F_{dc} = W \times g \times (\sin\theta - \mu \times \cos\theta)
$

6. **下降減速段($F_{dd}$)**
$
F_{dd} = W \times g \times (\sin\theta - \mu \times \cos\theta) - W \times a_{max}
$

7. **靜止段($F_{s}$)**
$
F_s = W \times g \times \mu
$

#### **(2) 平均軸向負載公式**

$
F_{eq} = \sqrt[3]{F_{ua}^3 \times \frac{t_{ua}}{T_{total}} + F_{uc}^3 \times \frac{t_{uc}}{T_{total}} + F_{ud}^3 \times \frac{t_{ud}}{T_{total}} + F_{da}^3 \times \frac{t_{da}}{T_{total}} + F_{dc}^3 \times \frac{t_{dc}}{T_{total}} + F_{dd}^3 \times \frac{t_{dd}}{T_{total}} + F_s^3 \times \frac{t_{s}}{T_{total}}}
$

#### **螺桿轉速代號與計算公式**

螺桿的轉速分以下情況進行計算：

1. **等速上升或下降條件(適用於 $t_{ac}, t_{dc}$)**
   - 在等速上升($t_{ac}$)或等速下降($t_{dc}$)條件下，螺桿的轉速按最大速度 $v_{max}$ 計算：
     $
     n_{screw,rev/s} = \frac{v_{max}}{l}
     $
     $
     n_{screw,rpm} = n_{screw,rev/s} \times 60
     $

   - 計算馬達的對應轉速：
     $
     n_{motor,rpm} = n_{screw,rpm} \times GR
     $

   - **若$n_{motor,rpm} > n_{motor,rated}$**，需要重新調整螺桿速度 $v_{ref}$：
     $
     v_{ref} = \frac{n_{motor,rated} \times l}{GR \times 60}
     $
     並重新計算螺桿的轉速：
     $
     n_{screw,rev/s} = \frac{v_{ref}}{l}, \quad n_{screw,rpm} = n_{screw,rev/s} \times 60
     $

2. **加速或減速條件(適用於 $t_{ua}, t_{ud}, t_{da}, t_{dd}$)**
   - 在上升加速($t_{ua}$)、上升減速($t_{ud}$)、下降加速($t_{da}$)、下降減速($t_{dd}$)條件下，螺桿的瞬時速度按加速度和加速時間計算：
     $
     v_{ref} = a_{max} \times t_{acc}
     $

   - 螺桿轉速計算為：
     $
     n_{screw,rev/s} = \frac{v_{ref}}{l}
     $
     $
     n_{screw,rpm} = n_{screw,rev/s} \times 60
     $

   - 計算馬達對應的轉速：
     $
     n_{motor,rpm} = n_{screw,rpm} \times GR
     $

   - **若 $n_{motor,rpm}$ > $n_{motor,rated}$**，需要重新計算：
     $
     v_{ref} = \frac{n_{motor,rated} \times l}{GR \times 60}
     $
     並重新計算螺桿轉速：
     $
     n_{screw,rev/s} = \frac{v_{ref}}{l}, \quad n_{screw,rpm} = n_{screw,rev/s} \times 60
     $

3. **靜止條件(適用於 $t_{s}$)**
   - 在靜止條件下，螺桿的轉速為：
     $
     n_{screw,rev/s} = 0, \quad n_{screw,rpm} = 0
     $

#### **螺桿轉速符號描述**
$
n_{i} \quad (i = ua, uc, ud, da, dc, dd, s)
$

螺桿的轉速 $n_{i}$ 根據 7 種運轉狀況分別計算 (i = ua, uc, ud, da, dc, dd, s)：

1. **上升加速段**
   $
   n_{ua} = \min\left(\frac{a_{max} \times t_{acc}}{l} \times 60, \frac{n_{motor,max}}{GR}\right)
   $

2. **上升等速段**
   $
   n_{uc} = \min\left(\frac{v_{max}}{l} \times 60, \frac{n_{motor,max}}{GR}\right)
   $

3. **上升減速段**
   $
   n_{ud} = \min\left(\frac{a_{max} \times t_{acc}}{l} \times 60, \frac{n_{motor,max}}{GR}\right)
   $

4. **下降加速段**
   $
   n_{da} = \min\left(\frac{a_{max} \times t_{acc}}{l} \times 60, \frac{n_{motor,max}}{GR}\right)
   $

5. **下降等速段**
   $
   n_{dc} = \min\left(\frac{v_{max}}{l} \times 60, \frac{n_{motor,max}}{GR}\right)
   $

6. **下降減速段**
   $
   n_{dd} = \min\left(\frac{a_{max} \times t_{acc}}{l} \times 60, \frac{n_{motor,max}}{GR}\right)
   $

7. **靜止狀態段**
   $
   n_{s} = 0
   $

#### **(3) 平均轉速公式**

$
n_{eq} = \frac{n_{ua} \times t_{ua} + n_{uc} \times t_{uc} + n_{ud} \times t_{ud} + n_{da} \times t_{da} + n_{dc} \times t_{dc} + n_{dd} \times t_{dd} + n_{s} \times t_{s}}{t_{ua} + t_{uc} + t_{ud} + t_{da} + t_{uc} + t_{dd} + t_{s}}
$

---

#### **補充說明**

1. **轉速與馬達轉速的關係：**
   - 螺桿轉速與馬達轉速的關係為：
     $
     n_{motor,rpm} = n_{screw,rpm} \times GR
     $

2. **程式邏輯：**
   - 程式可自動輸出各段的螺桿轉速 $n_{i}$, $\!$ (i = ua, uc, ud, da, dc, dd, s)。
   - 計算時，需保證馬達轉速 $n_{motor,rpm}$ 不超過馬達額定轉速 $n_{motor,rated}$。
   - 若計算的馬達轉速 $n_{motor,rpm}$ 超過馬達額定轉速 $n_{motor,rated}$，程式將自動調整對應段的螺桿速度 $v_{ref}$ 並重新計算。

#### **(4) 壽命公式**

1. **螺桿壽命公式（基本迴圈次數）**
- 螺桿壽命的總迴轉次數($L_{rev}$)計算公式為：
  $
  L_{rev} = \left( \frac{C_{a}}{F_{eq} \times f_{w}} \right)^3 \times 10^6
  $

  #### 說明：
  - $L_{rev}$：疲勞壽命，單位為 **${rev}$**。
  - $C_{a}$：基本動額定負荷，單位為 **${N}$**。
  - $F_{eq}$：軸向負荷，單位為 **${N}$**。
  - $f_{w}$：負荷係數(無單位，詳見負荷係數 **$f_{w}$** 表)

2. **螺桿壽命公式（總運行時間）**
- 將總迴轉次數($L_{rev}$)轉換為總運轉時間($L_{t}$)：
  $
  L_{t} = \frac{L_{rev}}{60 \times n_{eq}}
  $

  #### 說明：
  - $L_{t}$：螺桿總運行時間，單位為 **${hr}$**。
  - $n_{eq}$：平均轉速，單位為 **${rpm}$**。
 
3. **螺桿壽命公式（總行程）**
- 將總迴轉次數($L_{rev}$)轉換為總行程距離($L_{s}$)：
  $
  L_{s} = \frac{L_{rev} \times l}{10^6}
  $

  #### 說明：
  - $L_{s}$：螺桿總行程距離，單位為 **${km}$**。
  - ${l}$：螺桿導程，預設單位為 **${mm}$**。

4. **需求動額定負荷($C_{ac}$)定義**
$
C_{ac} = F_{eq} \times f_w \times \left( \frac{60 \times n_{eq} \times L_t}{10^6} \right)^{\frac{1}{3}}
$

#### 說明：
  - $C_{ac}$：需求螺桿動額定負荷， 預設單位為 **${N}$**。
  - $F_{eq}$：軸向負荷，單位為 **${N}$**。
  - $f_{w}$：負荷係數(無單位，詳見負荷係數 **$f_{w}$** 表)
  - $n_{eq}$：平均轉速，單位為 **${rpm}$**。
  - $L_{t}$：螺桿總運行時間，單位為 **${hr}$**。
  
#### **(5) 靜態安全係數公式**
靜態安全檢查：
$
S_{0} = \frac{C_{oa}}{F_{max}}
$

#### 說明：
- $S_{0}$：靜態安全係數，通常要求 $S_{0} \geq 1.5$。
- $C_{oa}$：螺桿靜額定負荷規格，單位為 **${N}$**。
- $F_{max}$：靜態負載，單位為 **${N}$**。

#### **(6) 臨界轉速公式**
$
n_{c} = \frac{K \times 10^7}{L^2}
$
- $n_c$：臨界轉速(rpm)。
- $K$：支撐係數，根據支撐方式選取(例如：固定-固定為 4.48，固定-自由為 1.57)。
- $L$：螺桿有效支撐長度(mm)。

#### **(7) 臨界載荷公式**
1. **Euler 挫曲公式（臨界載荷計算）：**
$
P = \alpha \frac{\pi^2 \times C_{N} \times E \times I}{L^2}
$

2. **螺桿半徑 \( dr \) 計算公式：**
若加入支撐條件修正：
$
d_{r} = \sqrt[4]{\frac{P \times L^2}{m \times N \times 10^3}}
$

#### 說明：
  - ${P}$：容許軸向負荷(kgf)。
  - $\alpha$：安全係數(取 $\alpha = 0.5$)
  - ${E}$：縱彈性係數($E = 2.1 \times 10^4 \, \text{kgf/mm}^2 $)
  - ${I}$：螺桿的軸截面之最小二次力矩($I = \frac{\pi dr^4}{64} \, \text{mm}^4$)
  - $d_{r}$：螺桿軸牙底直徑($d_{r}$ = 螺桿節圓直徑減鋼珠直徑，單位：mm)
  - ${L}$：安裝間距(螺桿兩端安裝之相對距離，單位：mm)
  - $C_{m}$：剛性修正係數，依 $Sup_{s}$ 表中數據選取。
  - $C_{N}$：臨界載荷修正係數，依 $Sup_{s}$ 表中數據選取。
  
#### **條件應用說明**
- **支撐條件的選擇：** 根據實際支撐方式選擇對應的 $C_{m}$ 和 $C_{N}$。例如：
  - 若結構兩端固定，選擇固定-固定，則 $C_{m} = 20.30、C_{N} = 4.00$。
  - 若結構一端固定、一端自由，選擇固定-自由，則 $C_{m} = 1.30、C_{N} = 0.25$。

- **計算結果應用：**
  1. 使用計算公式計算螺桿臨界載荷或截面半徑。
  2. 確保單位一致（長度統一為 mm）。
  3. 根據應力分析和結果驗算結構穩定性。

#### **(8) 馬達功率公式**
$
P_{req} = \frac{T_{motor,rated} \times n_{motor,rated}}{9550}
$

#### 說明：
- $P_{req}$：螺桿所需馬達功率，預設單位為 **${kW}$**。 
- $T_{motor,rated}$：馬達額定扭力規格，單位為 **${Nm}$**。
- $n_{motor,rated}$：馬達額定轉速規格，單位為 **${rpm}$**。

### **(9) 推力、扭力公式**
#### **1. 推力公式**
$
F_{req} = \frac{T_{motor,rated} \times 2 \pi \times \eta \times GR}{l} = \frac{T_{motor,rated} \times 2 \pi \times \eta \times \left( \frac{\text{馬達端齒輪齒數}}{\text{螺桿端齒輪齒數}} \right)}{l} = \frac{T_{motor,rated} \times 2 \pi \times \eta \times N_m}{l \times N_s}
$

#### **2.扭力公式**
$
T_{req} = \frac{F_{i} \times l}{2 \pi \times \eta \times GR} = \frac{F_{i} \times l}{2 \pi \times \eta \times \left( \frac{\text{馬達端齒輪齒數}}{\text{螺桿端齒輪齒數}} \right)}= \frac{F_{i} \times l \times N_{s}}{2 \pi \times \eta \times N_{m}}
$

#### 說明：
1. **參數：**
   - $F_{i}$：電動缸軸向推力，單位為 **${N}$**。
   - $F_{req}$：由馬達扭力估算螺桿所產生的推力，預設單位為 **${N}$**。
   - $T_{motor,rated}$：馬達額定扭力規格，單位為 **${Nm}$ 或 ${kgf-m}$**。
   - $T_{req}$：螺桿所需扭矩，預設單位為 **${Nm}$**。
   - ${l}$：螺桿導程，預設單位為 **${mm}$**。
   - $\eta$：機械效率，整體電動缸、馬達、皮帶輪系統的率效。
   - $GR$：減速比，無單位，可根據以下條件計算：
   - $N_{m}$：馬達端皮帶輪齒數。
   - $N_{s}$：螺桿端皮帶輪齒數。
