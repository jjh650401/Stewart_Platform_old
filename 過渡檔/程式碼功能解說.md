### **專案 v1.7 開發分支 - 完整程式碼功能解說**

#### **根目錄 (`/`)**

* **`main.py`**
    * **角色**：應用程式**啟動器 (Launcher)**。
    * **功能解說**：這是整個專案的進入點。它的職責非常單純：
        1.  初始化 Qt 應用程式環境 (`QApplication`)。
        2.  建立主視窗 `MainWindow` 和 3D 預覽視窗 `PyVistaWidget` 的實例。
        3.  設定這兩個視窗在螢幕上的初始位置與大小，使其並排顯示。
        4.  啟動應用程式的事件迴圈，讓程式開始運行並等待使用者互動。

* **`requirements.txt`**
    * **角色**：專案**依賴項清單**。
    * [cite_start]**功能解說**：此檔案列出了執行本專案所需的所有第三方 Python 函式庫 [cite: 1]。主要包含：
        * [cite_start]`numpy`, `scipy`：用於所有核心的科學計算、矩陣運算與最佳化求解 [cite: 1]。
        * [cite_start]`PyQt6`：提供圖形使用者介面 (GUI) 的核心框架 [cite: 1]。

        * [cite_start]`reportlab`: 為未來生成 PDF 報告的功能預留 [cite: 1]。

#### **核心計算層 (`/src/core/`)**

* **`config.py`**
    * **角色**：中央**設定檔**。
    * **功能解說**：此檔案將所有可調整的「魔術數字」從程式碼邏輯中分離出來，集中管理。包含了 3D 視覺化的樣式（顏色、線寬）、GUI 控制項的預設值（滑塊範圍、精度）、以及核心計算求解器的容許誤差等。

* **`kinematics.py` (Class: `CoreEngine`)**
    * **角色**：專案的**運動學大腦**與參數中心。
    * **功能解說**：這是處理所有幾何與運動學計算的核心。
        1.  **參數管理**：儲存與管理平台的所有幾何與物理參數。
        2.  **逆向運動學 (IK)**：`_calculate_leg_lengths_from_ui_pose` 方法是核心 IK 引擎，根據給定姿態計算致動器長度。
        3.  **幾何求解**：負責計算衍生參數，如平台半徑 `Ra`/`Rb`，以及最重要的**零位高度 `H`**。
        4.  **工作空間分析**：透過 `analyze_operational_workspace` 等方法，使用 `SciPy` 的 `SLSQP` 最佳化演算法，高效地求解平台在行程限制下的運動邊界。
        5.  **姿態驗證**：提供 `is_pose_valid` 介面，用於快速檢查一個給定的姿態是否在物理上可達。
        6.  **檔案處理**：負責將專案的所有參數序列化儲存為 `.json` 檔案，或從中讀取。

* **`dynamics_engine.py` (Class: `DynamicsEngine`)**
    * **角色**：專案的**動力學心臟**。
    * **功能解說**：專門負責處理逆動力學計算。
        1.  **逆向動力學 (ID)**：其主要方法 `calculate_actuator_forces` 根據平台的姿態、負載以及加速度，計算出每根致動器所需的瞬時出力。
        2.  **雅可比矩陣**：內部會建構平台的扳手矩陣 (Wrench Matrix / Jacobian)，這是動力學計算的基礎。
        3.  **通用性**：能夠正確處理 6-DOF 和 3-DOF 兩種平台。特別是對於 3-DOF，它使用了數學上更穩健的偽逆矩陣 (`np.linalg.pinv`) 來求解，確保了計算的準確性。

* **`analysis_engine.py` (Class: `AnalysisEngine`)**
    * **角色**：**高耗能分析工作者 (Worker)**。
    * **功能解說**：此模組被設計用來在獨立的背景執行緒中，執行耗時的「全域最大靜載分析」，避免主視窗凍結。
        1.  **LHS+SQP 演算法**：完整實作了《全域最大靜載推力計算演算法》中定義的混合智慧演算法。
        2.  **執行緒安全**：它被設計為一個無狀態的物件，透過訊號與槽 (`pyqtSignal`) 的方式安全地與主執行緒通訊，回報進度與最終結果。

#### **圖形介面層 (`/src/gui/`)**

* **`main_window.py` (Class: `MainWindow`)**
    * **角色**：應用程式的**總指揮官**與**事件協調中心**。
    * **功能解說**：
        1.  **UI 組合**：建立並組織所有 UI 元件，例如使用 `QTabWidget` 來管理不同的功能面板。
        2.  **訊號與槽連接**：這是它最重要的職責。它將來自各個 UI 元件的訊號（如按鈕點擊）連接到 `CoreEngine` 或其他後端模組的對應槽函式（計算邏輯）上。
        3.  **執行緒管理**：負責建立、啟動和清理 `AnalysisEngine` 的背景執行緒，並處理其回傳的訊號。
        4.  **狀態協調**：呼叫 `StateManager` 來管理應用程式的整體狀態，例如檔案是否已儲存 (`is_dirty`)。
        5.  **資料流控制**：負責在各模組間傳遞資料。例如，將 `CoreEngine` 計算出的工作空間結果，傳遞給 `AnalysisWidget` 來更新滑塊範圍。

* **`pyvista_widget.py` (Class: `PyVistaWidget`)**
    * **角色**：專用的 **3D 渲染畫布**。
    * **功能解說**：
        1.  **嵌入 3D 場景**：使用 `pyvistaqt` 將一個高效能的 VTK 渲染視窗嵌入到 PyQt 應用程式中。
        2.  **繪圖API**：提供 `rebuild_scene` (用於首次繪製或徹底刷新) 和 `update_platform_pose` (用於高效、無閃爍的姿態更新) 兩個核心繪圖方法。
        3.  **場景管理**：負責繪製平台骨架、致動器連桿、節點標籤等所有 3D 物件。
        4.  **視角控制**：管理 3D 攝影機的所有操作，包括預設視角、視角歷史堆疊等。

* **`geometry_widget.py` (Class: `GeometryWidget`)**
    * **角色**：**UI 元件產生器 (Builder)**。
    * **功能解說**：它本身不是一個獨立顯示的介面。它的作用是提供一系列 `create_..._group` 方法，用於產生可重複使用的 UI 區塊（如下平台、上平台、致動器等群組），專門供 `six_dof_widget.py` 呼叫，以避免重複編寫相同的 UI 程式碼。

#### **圖形介面控制項 (`/src/gui/controls/`)**

* **`master_geometry_widget.py` (Class: `MasterGeometryWidget`)**
    * **角色**：幾何設計面板的**切換器 (Switcher)** 與**訊號路由器 (Router)**。
    * **功能解說**：
        1.  包含「六自由度」和「三自由度」的選項按鈕。
        2.  使用 `QStackedWidget` 根據使用者的選擇，顯示對應的 `SixDofWidget` 或 `ThreeDofWidget`。
        3.  將來自子元件的訊號（如 `parameters_confirmed`）直接轉發給上層的 `MainWindow` 處理。

* **`six_dof_widget.py` & `three_dof_widget.py`**
    * **角色**：**參數輸入面板**。
    * **功能解說**：分別為 6-DOF 和 3-DOF 平台提供專屬的參數輸入介面。它們負責接收使用者的手動輸入，並在按鈕被點擊時，發射對應的訊號，通知 `MainWindow` 採取下一步行動。

* **`analysis_widget.py` (Class: `AnalysisWidget`)**
    * **角色**：**姿態控制與分析結果顯示面板**。
    * **功能解說**：
        1.  **姿態控制**：提供一組滑塊，讓使用者可以手動控制平台的姿態。當滑塊移動時，會發出 `pose_changed` 訊號。
        2.  **工作空間顯示**：負責接收由 `MainWindow` 傳遞過來的工作空間分析結果，並動態更新滑塊的可動範圍與顯示標籤。
        3.  **姿態展演**：包含了「自動展演」功能的完整 UI 與計時器邏輯。

* **`dynamics_widget.py` (Class: `DynamicsWidget`)**
    * **角色**：**動力學參數輸入與結果顯示面板**。
    * **功能解說**：
        1.  **參數輸入**：提供介面讓使用者輸入質量、負載質心、加速度等動力學參數。
        2.  **結果顯示**：負責顯示「當前姿態出力」和「全域最大靜載」的計算結果。
        3.  **觸發計算**：包含觸發計算的按鈕，點擊後會發射訊號，由 `MainWindow` 捕捉並啟動對應的分析流程。
