螺桿篩選公式
需求動額定負荷 (C_ac)
[C_{ac} = F_{eq} \times f_w \times \left( \frac{60 \times n_{eq} \times L_T}{10^6} \right)^{\frac{1}{3}}]

參數：
F_eq：等效軸向負荷 (N)，由系統計算。
f_w：負荷係數，根據 v_max (m/min)：
v_max < 15：1.0 ≤ f_w ≤ 1.2
15 ≤ v_max < 60：1.2 ≤ f_w ≤ 1.5
v_max ≥ 60：1.5 ≤ f_w ≤ 3.0


n_eq：平均轉速 (rpm)，由系統計算（n_eq = (v_max / lead_mm) * 60 * 1000）。
L_T：需求壽命 (hr)，由使用者輸入：[L_T = hours_per_day \times days_per_year \times expected_years \times duty_cycle]
預設：hours_per_day = 8, days_per_year = 250, expected_years = 5, duty_cycle = 0.8。
示例：L_T = 8 * 250 * 5 * 0.8 = 8,000 hr。





額定疲勞壽命 (L_t)
[L_t = \frac{10^6}{60 \times n_{eq}} \times \left( \frac{ca_n}{F_{eq} \times f_w} \right)^3]

參數：
ca_n：螺桿額定動負荷 (N)，從資料庫 (screws 表) 取得。
F_eq, f_w, n_eq：同上。


驗證：檢查 L_t >= L_T，確保螺桿壽命滿足需求。

所需導程 (required_lead_mm)
[required_lead_mm = \frac{v_max \times 1000 \times 60}{rated_rpm \times ratio}]

參數：
v_max：最大速度 (m/min)，由使用者輸入。
rated_rpm：馬達額定轉速 (rpm，例如 1500、2000、3000)。
ratio：皮帶輪減速比（常用值：2）。


用途：篩選 lead_mm 接近 required_lead_mm 的螺桿（例如，±10% 範圍）。
